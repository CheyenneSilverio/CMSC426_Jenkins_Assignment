# CMSC 426 Jenkins CI Assignment

## Project Description
This project demonstrates Continuous Integration (CI)
using Jenkins, GitHub, and Python.

## Application
The application contains a Python function that adds
two numbers together.

## Automated Tests
The project uses Python's unittest framework to test
the application's functionality.

## How to Run the Application
python app.py

## How to Run the Tests
python -m unittest discover -s tests -v

## CI Workflow
Jenkins will retrieve the project from GitHub,
execute automated tests, and report build results.
